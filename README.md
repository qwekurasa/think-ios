# think для iPhone

Распакуйте архив на Mac и откройте Think.xcodeproj в Xcode 15 или новее. Выберите схему Think и симулятор iPhone с iOS 17 или новее, затем нажмите Run. Для установки на свой iPhone выберите свою команду в Signing & Capabilities и укажите доступный Bundle Identifier.

Коснитесь звезды для ввода. Новая незавершённая мысль сохраняется как черновик. Из коллекции можно дополнить идею или показать её QR-код. Данные хранятся локально. Распознавание обычного текста зависит от приложения-сканера.

Одна звезда начисляется за запись, одна за 80 символов текста и одна за первый шаг. Баллы за достигнутый уровень выдаются однократно. В панели баланса можно открыть серебряную палитру за 5 звёзд. После покупки переключение палитр бесплатно.

Design.png — дизайн-превью с примером записи. При первом запуске коллекция пуста.
