# think — iOS

Минималистичное приложение для сохранения идей голосом и текстом. Интерфейс Sketch Edition выполнен как монохромный карандашный рисунок: живые неровные линии, рукописная типографика и белая бумажная поверхность.

## Возможности

- Живой карандашный шар на главном экране (SwiftUI Canvas) с неровными контурами и движущимися штрихами.
- Запись идей голосом через Speech и AVFoundation, текстовый редактор.
- Локальное хранение идей, редактирование, поиск.
- Бесплатные QR-коды с текстом, система звёзд и 7-дневный цикл возвращения к идеям.
- Сборка неподписанного `Think.ipa` в GitHub Actions для установки через Sideloadly.

## Как получить IPA

Откройте [Actions](https://github.com/qwekurasa/think-ios/actions), выберите **Think iOS IPA** и скачайте артефакт **Think-IPA-Sideloadly** после успешной сборки. В архиве находится `Think.ipa`. Sideloadly подпишет его при установке.

## Sketch Edition

- Белый фон и только чёрный/серый графит.
- Рукописная типографика Noteworthy.
- Неровные карандашные контуры для карточек, кнопок и иконок.
- Голосовой экран с рисованным микрофоном, волной и рамкой записи.
- QR-код остаётся функциональным и рисуется монохромными точками.

## Исходники и сборка

- `Think/Sources/` — приложение на SwiftUI.
- `make_project.py` — генератор Xcode-проекта и иконки на macOS runner.
- `Think.xcodeproj/xcshareddata/xcschemes/Think.xcscheme` — общая схема для сборки.
- `.github/workflows/think-ipa.yml` — GitHub Actions.

Ориентир: iOS 17+. Release: `1.6` (build `7`). Bundle ID: `com.think.ideas.personal` (сохранён для обновлений приложения).

Проект перенесён из ветки `think-ios-build` репозитория `qwekurasa/tempt`; исходная ветка сохранена без изменений.

## Think v2 — Sketch Edition (первый этап)

- Версия 2.0, build 8, прежний Bundle ID для сохранения идей при обновлении.
- Возобновление несохранённого текста после закрытия записи или перезапуска приложения.
- Рукописные заголовки с устойчивыми небольшими неровностями букв.
- Отдельные тесты жизненного цикла идеи (`Tests/ThinkIdeaRulesChecks.swift`), запускаются до сборки IPA.
